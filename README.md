# IKEA Product Price Prediction

## Project Overview
This project predicts IKEA furniture prices using Big Data Analytics, NLP, and Machine Learning techniques.

## Technologies Used
- PySpark
- Scikit-learn
- TF-IDF
- Decision Tree Regression
- Streamlit
- GitHub

## Features
- Data preprocessing
- Exploratory Data Analysis
- NLP text processing
- Machine learning prediction
- Interactive Streamlit dashboard
- Cloud deployment

## Machine Learning Models
- Linear Regression
- Decision Tree Regression

## Deployment
The project is deployed using Streamlit Cloud.
